What this tool does

This is a private, single-user command-line tool used only by the owner of the YouTube channel “1년 성경통독” to upload and schedule the owner’s own daily Bible-reading videos and Shorts through the YouTube API Services. It is not offered to any other user.

  • Uses one OAuth scope: https://www.googleapis.com/auth/youtube.upload
  • Calls one endpoint: videos.insert (with status.publishAt for scheduled publishing)
  • Does not read, analyze, or store any other YouTube data.
