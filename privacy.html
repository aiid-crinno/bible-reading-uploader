Privacy Policy · 개인정보처리방침

Effective date: November 13, 2026

1. About this tool and YouTube API Services

“1Year Bible Reading Uploader” is a private, single-user tool operated by the owner of the YouTube channel 1년 성경통독. It uses YouTube API Services to upload and schedule the owner’s own videos to the owner’s own channel. By using this tool, users agree to be bound by the YouTube Terms of Service. Google’s handling of data is described in the Google Privacy Policy.

2. Information accessed, collected, and stored

  • Google OAuth token (scope youtube.upload only): stored only as a local file on the owner’s own computer.
  • Upload log: the ID and scheduled publish time of each video the owner uploads, stored in a local CSV file.
  • The tool does not access, collect, or store any other YouTube or Google account data (no viewing data, comments, subscribers, analytics, or contacts). It does not use cookies or tracking technologies, and there is no hosted server.

3. How the information is used

The token is used solely to call the YouTube Data API videos.insert endpoint to upload the owner’s videos and set their scheduled publish time. The upload log is used only to keep track of which episodes have been uploaded.

4. Sharing

No information is shared with, sold to, or disclosed to any third party. Video files and metadata are sent only to YouTube (Google) through the YouTube API Services.

5. Deletion and revoking access

  • Access can be revoked at any time via the Google security settings page (Google Account → Third-party connections).
  • When access is revoked or the tool is no longer used, the local token file and upload log are permanently deleted from the owner’s computer within 7 days.
  • Uploaded videos can be deleted at any time in YouTube Studio; they remain subject to the YouTube Terms of Service and the Google Privacy Policy.

6. Contact

Questions about this policy: please open an issue at github.com/aiid-crinno/bible-reading-uploader/issues.
